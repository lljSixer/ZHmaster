ZHmaster 文件转换工作台 1.2.2

双击 ZHmaster.exe 运行。独立版本，不替换 1.0、1.1、1.2、1.2.1 或 D:\APPS\ZHmaster 中的程序。
适用于 64 位 Windows 10 / 11，需系统自带的 .NET Framework 4.7.2 或更新版本。
图片和音频转换不需要安装 Microsoft Word。Word 转换需要可用的办公软件环境。

1.2.2 性能改进

- 修复连续缩放时圆角边框与空列表区域的旧边框残影，减少重复擦除和绘制。
- 合并密集的窗口尺寸事件，并在持续拖动时定期应用最新布局；松开鼠标立即完成最终布局。
- 不再每次缩放遍历整个控件树或重复测量输入框文字，列宽只在需要时更新。
- 图片上移、下移和移除只更新相关列表条目；重复添加不会重建列表或清除选择。
- 后台进度与音频参数按最新值合并，拖动窗口期间推迟非关键刷新，空闲时停止刷新计时器。
- 音频完整性校验继续保留。大文件的解码、完整校验以及 Word 排版仍需要正常处理时间。
- 详细数据和验证范围见“1.2.2更新与性能说明.md”；不依赖新的常驻服务或额外运行时。

窗口与列表

- 可用鼠标拖动窗口四边或四角改变大小，也支持最大化和还原。
- 列表、路径输入框及表单会随窗口空间调整；文字字号保持稳定，底部操作栏跟随窗口底部。
- 最小客户区约为 980×680（100% 系统缩放），避免按钮和输入框重叠；实际像素尺寸随系统 DPI 调整。
- 空列表中显示图标和对应的拖拽提示，可直接将文件拖到提示区域。
- Word 和音频页先选择“保存方式”，再设置“保存位置”。选择“原文件所在文件夹”时，路径和浏览按钮禁用。
- 两种下拉框使用统一的填充背景，右侧统一提示“同名文件将自动添加序号”。
- 音频列表增加“时长”列，添加后在后台读取，不需要先开始转换。通常为 MM:SS，超过一小时为 H:MM:SS；无法读取时显示 --:--。

一、03 音频转 WAV

1. 点击“03 音频转 WAV”。
2. 点击“＋ 添加音频”，或将文件拖到列表里。支持 FLAC、OGG、OPUS、APE、WV、WAV。
3. 选择保存方式：指定保存位置，或原文件所在文件夹。
4. 点击“导出 WAV”。每个音频单独输出，列表显示时长、参数，以及检测、转换、校验和完成状态。
5. 完成后可打开保存位置，或在“转换记录”中查看音频参数和采样数据校验值。

精度与音质：
- 自动读取源音轨参数，不改变采样率和声道，不调整音量，不添加音效。
- 16 / 24 / 32 位整数音频选用对应或足够精度的 PCM；浮点解码数据使用 32 / 64 位浮点 WAV，避免额外量化和削波。
- FLAC 可以无损还原音频采样。OGG 是容器，常见 Vorbis / Opus 已经有损；导出 WAV 保留当前解码音质，不能恢复以前丢失的信息。
- 不确定可保留的采样精度时直接报错，不默默降为 16 位。
- 转换完成后，再解码源文件和输出 WAV，比较规范化 PCM 数据的 SHA-256，并检查采样率、声道、布局和输出编码。
- 通过校验才将临时文件改为正式 WAV。校验失败、转换失败或取消时会清理临时文件。
- 使用源文件的第一条音轨；不会将多个音轨混音为一条。
- WAV 通常比 FLAC / OGG 大，增加体积不会提高原有音质。
- 超过 4 GB 时使用 RF64 扩展，播放器也需支持 RF64。
- 32 / 64 位浮点 WAV 需使用支持相应精度的播放器；程序不会为兼容旧设备而默默降低精度。
- WAV 对封面和标签的支持不同于 FLAC / OGG；音频无损不代表所有封面、标签和文件头逐字保留。

保存与取消：
- 默认音频保存到程序目录中的“WAV输出”，与 PDF 保存位置分别记忆（本次运行内）。
- 已有同名文件时自动添加“(2)”“(3)”等序号，不覆盖已有文件或源 WAV。
- “取消”按钮仅在任务运行时显示。音频转换会停止当前自有解码进程，清理当前临时文件，保留之前已完成的结果。
- 完整校验需要额外读取音频，长音频的校验阶段可能比单纯改格式花更多时间。

音频组件已随程序附带，无需单独安装：
tools\ffmpeg\ffmpeg.exe
tools\ffmpeg\ffprobe.exe
请保留整个 tools 文件夹。它包含必要的转换程序、许可证与原始构建说明。
优先使用随程序提供的组件；若组件不在程序目录，会尝试同一 PATH 目录中配套的两个工具。
文件均在本机处理；音频组件只允许本地文件和进程管道，不进行网络媒体读取。

二、01 图片转 PDF

支持 JPG / JPEG / PNG / BMP，按列表顺序每图一页；可选原图比例或 A4 等比居中。
选中一个条目可上移、下移。PNG 透明区域使用白底，常见 EXIF 方向自动校正。
普通 JPG 保留原压缩数据。输出同名文件自动增加序号。

三、02 Word 转 PDF

支持 DOC / DOCX，每份文档独立生成 PDF，保留已有批量状态、指定保存位置及原目录保存功能。
优先使用初始化完成的 Microsoft Word 桌面版，也检测提供 KWPS.Application 接口的兼容 WPS 版本。
本机 Microsoft Word 已完成实际导出测试；WPS 分支未做实机验证。
以只读方式打开，不保存源文档修改，不运行文档宏。

四、通用交互

空列表时禁用无效操作；取消只在转换期间显示。
Ctrl+A 全选，Delete 从列表移除，不删除源文件。
三个页面的队列独立，底部操作栏固定，支持常见系统缩放布局。

五、项目与构建

source\AudioExporter.cs：音频参数读取、PCM 选择、解码、校验、取消和输出保护。
source\MainForm.cs：三个页面、独立队列、任务状态与进度。
source\MainForm.Layout.cs：窗口缩放、自适应布局、最小尺寸与列宽。
source\MainForm.Updates.cs：合并后台进度和参数更新，管理按需刷新的计时器。
source\MainForm.Metadata.cs：音频时长和参数的后台读取、缓存与取消。
source\WorkspaceViews.cs：空状态图标、自绘表头和填充下拉框。
source\ZHmaster.cs：程序入口、图片 PDF 和 Word 导出。
source\Controls.cs：主题控件。
source\build.ps1：使用 Windows .NET Framework 编译器构建，无 Python 运行依赖。
work：测试源代码、音频样本、布局预览、测试日志及旧版文件完整性记录。

可选命令行（窗口程序需等待退出并检查退出码）：
ZHmaster.exe --audio "D:\音频输出" "D:\歌曲.flac" "D:\歌曲.ogg"
ZHmaster.exe --images "D:\图片.pdf" "D:\1.jpg" "D:\2.png"
ZHmaster.exe --images-a4 "D:\A4.pdf" "D:\1.jpg"
ZHmaster.exe --word "D:\PDF输出" "D:\文档.docx"
失败时返回 1，详细原因记录在程序目录的 last-error.txt。
